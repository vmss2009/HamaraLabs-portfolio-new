# Hamaralabs portfolio site

- a portfolio website that explains the services I provide

## features

- a blog page, directly connected to a google drive folder though which it accesses all blog posts, a very simple and minimalistic integration without the use of any database
- a buy page, it has "real payment integratio"
  - it was a struggle to get the backend ready for phone payment gateway
- clicking "book a free session" opens a direct whatsapp link

## How to replicate it ?

1. Clone the repo
2. Run "npm start"
3. Access it on browser and you are all set !
