# Hamaralabs portfolio site

- a portfolio website that explains the services I provide

## features

- a blog page, directly connected to a google drive folder though which it accesses all blog posts, a very simple and minimalistic integration without the use of any database
- a buy page, it has "real payment integration"
  - it was a struggle to get the backend ready for phone pe payment gateway
- clicking "book a free session" opens a direct whatsapp business link

## How to replicate it ?

1. Clone the repo
2. Install node dependencies
3. Run "npm start"
4. Access it on browser and you are all set !
